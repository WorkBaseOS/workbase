# 03-projects — work with an end

Time-bound work lives here: a launch, a hire, a migration, a campaign. One folder per project; when it's done, it moves to the archive.

**What belongs here:** work that will be finished someday.
**What never belongs here:** ongoing responsibilities — those are operations.
**The one rule:** every project folder carries `_overview.md` — same pattern as operations, plus a deadline where a real one exists. Say **"set up a project for …"** and your assistant creates the folder and its overview in the standard shape, asking only what matters: the goal, and a deadline only where a real one exists. Not sure what something is? A finish line → project. Never ends → operation. Your own craft → desk.
