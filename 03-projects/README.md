# 03-projects — work with an end

Time-bound work lives here: a launch, a hire, a migration, a campaign. One folder per project; when it's done, it moves to the archive.

**What belongs here:** work that will be finished someday.
**What never belongs here:** ongoing responsibilities — those are operations.
**The one rule:** the folder holds the work itself — the plan, the notes, the drafts on top, what came in under `received/`. The deadline and every promise live in the plan or the notes, not in a separate register. Add a short summary file only if this project benefits from one. Say **"set up a project for …"** and your assistant creates the folder, asking only what matters. Not sure what something is? A finish line → project. Never ends → operation. Your own craft → desk.
