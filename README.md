# WorkbaseOS

Your AI business workspace in Claude. Set it up once. Put it to work every day.

WorkbaseOS is a folder of plain files that turns Claude Code into a working assistant for one owner, operator or manager: it holds what the assistant should always know about you, where your work lives, and the skills it runs for you, from meeting minutes to the quarterly plan. It is taught in the Udemy course that goes with it, and this repository is its home.

## Get it

Download the latest **Workbase.zip** from the [Releases](../../releases) page, unzip it, give the folder a permanent home, and open it in Claude Code. The folder's own `START-HERE.md` takes it from there. No GitHub account and no Git are needed.

Students of the course get the same zip under the lesson in which it is introduced.

## What is inside

- `START-HERE.md`, the one page to read first.
- `AGENTS.md`, the rules the assistant works by; `CLAUDE.md` points Claude at it.
- `00-brain`, what it should always know; `01-in-tray`, where things land; `02-operations`, `03-projects`, `90-desks`, the work; `99-archive`, finished work.
- `.claude/skills`, the skills; `.agents/skills`, the same set for Codex.

Everything is yours to change, by hand or by asking the assistant. A later version of the template never replaces a file you have changed.

## Updates and what comes after the course

New versions of the zip and new skills appear here. Watch the repository to be told when they do.
