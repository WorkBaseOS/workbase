# Agents

Your own specialists live here, one file each: a sub-agent the assistant sends off with a job and a fresh chat of its own, which reports back only the answer. Ask for one in plain words ("create a sub-agent called scout that…") and the assistant writes the file: settings on top (name, when to use it, what it may touch, which model), instructions below. The folder ships with two things: the **scout** (`scout.md`), which briefs you on a company before a first call ("brief me on <company>"), and the five seats of the **panel** (`seat-*.md`), which the panel skill sends off as a team ("run the panel"). Open one to see the shape; change a seat if your business needs a different question. A folder created during a session is not watched until the next one, which is why this folder ships filled. Agents are read by Claude Code; Codex does not read this folder.
