# Handoff

One question, one file, a short recap when you return.

## Saving a handoff

Ask one question: **"Where are you leaving things, and what's the next step?"** The owner answers naturally. If the conversation already contains the relevant information, draft a short summary instead and ask **"Is this right?"**

Save three things in `HANDOFF.md`, under the current project or work context (a heading per context; "General" when the work isn't tied to one):

- **Current status** — what's done and where the work stands.
- **Open items** — unfinished work, blockers, or decisions still needed.
- **Next step** — the concrete action to start with when they return.

Add the last-updated date. Each handoff updates that context's section in the same file, carrying forward unresolved open items so they don't disappear. If something is unknown, say so rather than inventing a status.

## Resuming work

On "where did I leave off?" or "resume from my handoff", read the file and give a brief recap: **"You finished X. Y is still open. Your next step is Z."** Enough context to continue without rereading the previous conversation. Only start doing the work if the owner asks.

## Keep it simple

No daily routine, no questionnaire, no review. Nothing else in the Workbase changes when a handoff is saved.
